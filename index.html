B.A.B — Beauty Assistant Bot
نظام الدعم الفني الذكي المعتمد لمتجر DANDY
↗️ لوحة التحكم 🛍️ المتجر المستقل

📋 نظرة عامة على المشروع والهندسة البرمجية

B.A.B (Beauty Assistant Bot) هو مساعد خدمة عملاء رقمي قائم على القواعد المعتمدة (Rule-based) مخصص لمتجر DANDY لمستحضرات التجميل والعناية.

🚫 خالٍ تماماً من الذكاء الاصطناعي التوليدي:

لا يقوم باختراع أي إجابات أو الاعتماد على نماذج خارجية أو رسوم اشتراكات.

⚡ محرك بحث عربي محلي 100%:

تطبيع الحروف العربية، تجاهل التشكيل والتطويل، وتسامح مع الأخطاء الإملائية الشائعة.

🛡️ مكون ويب أصيل (Shadow DOM):

عزل كامل للأنماط والـ CSS بحيث لا يؤثر على مظهر متجر DANDY الأصلي ولا يتأثر به.

🚀 خطوات ربط المساعد بمشروع DANDY الفعلي

لإدراج B.A.B في متجر DANDY لاحقاً دون تعديل كود جافاسكريبت أو فايربيس الأصلي، يتم نسخ الملفات الجاهزة إلى مجلد الـ assets:

1. هيكل المجلدات النهائي في مشروع DANDY:

public/ └── assets/ └── bab/ ├── widget/ │ ├── bab-widget.js │ └── bab-widget.css │ └── data/ └── knowledge.json

2. إدراج المكون في ملف القالب العام (BaseLayout.astro):

يتم إضافة السطرين التاليين فقط قبل إغلاق وسم </body>:

<!-- DANDY B.A.B Customer Support Assistant Widget --> <dandy-bab-widget knowledge-src="/assets/bab/data/knowledge.json"> </dandy-bab-widget> <script type="module" src="/assets/bab/widget/bab-widget.js"> </script>

3. تموضع الزر وعدم التعارض:

تم تصميم المساعد بحيث يطفو في أسفل اليسار (Bottom-Left) مع مسافة أمان رأسية تلقائية على الهواتف المحمولة لعدم التعارض مع شريط التنقل السفلي لمتجر DANDY، ومع زر واتساب الدائم العائم في أسفل اليمين (Bottom-Right).

💻 تشغيل المشروع محلياً (Local Running)

المشروع خفيف جداً ولا يتطلب خادماً خلفياً أو تثبيت أطر عمل ثقيلة. لتشغيله محلياً عبر أي خادم ويب ثابت (مثل Python أو Node):

# باستخدام بايثون 3 (موصى به لمستخدمي Windows / Mac / Linux): python -m http.server 8000 # أو باستخدام Node.js npx serve: npx serve . # ثم افتحي المتصفح على: http://localhost:8000
