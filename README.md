## 💎 نظرة عامة على المشروع

**B.A.B (Beauty Assistant Bot)** هو نظام دعم فني وتوجيه ذكي ومستقل لعملاء متجر **DANDY** لمستحضرات التجميل والعناية بالبشرة والشعر (`https://dandy-ebon.vercel.app`).

### المبادئ الأساسية:
- **نظام قائم على القواعد بنسبة 100% (Deterministic Rule-Based System):** لا يستخدم أي نموذج ذكاء اصطناعي توليدي (No OpenAI, No Gemini, No Claude, No LLM APIs).
- **مجاني تماماً وبدون أي تكلفة تشغيلية (Zero Operating Cost):** يعمل محلياً بالكامل داخل متصفح المستخدم دون الحاجة لأي خادم خلفي (Serverless / Static).
- **مكون ويب أصيل معزول (Native Web Component with Shadow DOM):** معزول تماماً بداخل عنصر `<dandy-bab-widget>` لضمان عدم تأثر أو تداخل أنماط CSS أو أكواد JavaScript مع موقع المتجر.
- **جاهز للاستخدام الفوري (Production-Ready Out of the Box):** مزود بقاعدة معرفة عربية متكاملة تضم **56 سؤالاً وجواباً** موزعة على **8 أقسام رئيسية** معتمدة رسمياً.
- **لوحة تحكم إدارية مدمجة (Local Admin Dashboard):** تمكّن فريق المتجر من إدارة الأقسام والأسئلة والكلمات المفتاحية والاستيراد والتصدير دون الحاجة لأي مهارات برمجية.

## 📚 قاعدة المعرفة الجاهزة مسبقاً

تم إعداد وتدقيق قاعدة المعرفة في ملفي `data/knowledge.json` و `public/assets/bab/data/knowledge.json` لتشمل **56 مقالة دعم فني احترافية** تغطي أدق تفاصيل رحلة العميل على متجر DANDY دون اختلاق أي سياسات غير مؤكدة:

### الأقسام الثمانية المعتمدة ومحتوياتها:
1. **الطلبات والشراء (orders - 8 مقالات):**
   - كيفية عمل طلب جديد خطوة بخطوة وإضافة المنتجات للسلة.
   - إتمام الشراء والدفع عند الاستلام.
   - إمكانية تعديل أو إلغاء الطلب (توجيه لواتساب لمراجعة حالة التجهيز).
   - مراجعة محتويات السلة ومتابعة الطلب بعد تأكيده.
   - حل مشكلة عدم استلام رسالة تأكيد الطلب.

2. **الشحن والتوصيل (shipping - 8 مقالات):**
   - **مدة التوصيل المعتمدة:** 2 إلى 5 أيام عمل لجميع المحافظات.
   - **تغطية الشحن:** التوصيل لجميع محافظات جمهورية مصر العربية.
   - **تكلفة الشحن:** متغيرة ومحسوبة بدقة بناءً على عنوان المحافظة عند إتمام الطلب (لا يُعرض سعر ثابت أبداً).
   - **الشحن المجاني المعتمد:** متاح للطلبات التي تتجاوز قيمتها الإجمالية **2,000 جنيه مصري**.
   - التعامل المهني مع تأخر الشحنات، والتوجيه لواتساب فوراً في حال وصول شحنة تالفة.

3. **تتبع الطلبات (tracking - 5 مقالات):**
   - توجيه مباشر لصفحة التتبع الرسمية: `https://dandy-ebon.vercel.app/track-order`.
   - شرح مكان العثور على رقم التتبع (رسائل SMS والبريد الإلكتروني وتفاصيل الحساب).
   - حلول تعطل صفحة التتبع وعدم تحديث حالة الشحنة.
   - **قاعدة الخصوصية:** لا يطلب المساعد مطلقاً رقم الهاتف أو كود الطلب السري داخل الشات، بل يوجه العميل لأداة التتبع الرسمية.

4. **المنتجات والعناية الشخصية (products - 10 مقالات):**
   - استعراض الأقسام والتصنيفات الأربعة الرئيسية بروابطها المعتمدة:
     - العناية بالشعر: `/category/hair-care`
     - العناية بالبشرة: `/category/skin-care`
     - العناية بالجسم: `/category/body-care`
     - العطور الفاخرة: `/category/fragrance`
     - جميع المنتجات: `/all-products`
     - العروض الحصرية: `/special-offers`
   - نصائح اختيار الروتين المناسب وطلب استشارة موظفي المتجر عبر واتساب.
   - **قاعدة الأمان الطبي:** المساعد لا يختلق مكونات أو مزاعم طبية غير معتمدة.

5. **الدفع والاسترجاع والاستبدال (returns - 7 مقالات):**
   - طرق الدفع المعتمدة (الدفع عند الاستلام COD وتأكيد الدفع الإلكتروني عبر المتجر).
   - سياسة استبدال واسترجاع المنتجات واستلام منتج غير مطابق أو تالف.
   - التوجيه الفوري لخدمة عملاء واتساب لمراجعة طلبات الاسترجاع مع إرفاق رقم الطلب وصورة الشحنة.

6. **الحساب والمستخدم (account - 6 مقالات):**
   - إنشاء حساب جديد عبر `/account-signup`.
   - تسجيل الدخول عبر `/account-login`.
   - استعادة وتعيين كلمة المرور وإدارة العناوين عبر `/account`.
   - حل مشاكل تسجيل الدخول وتحديث البيانات الشخصية.

7. **الموقع والمساعدة التقنية (technical - 6 مقالات):**
   - حلول مشاكل عدم استجابة سلة المشتريات أو صفحة الدفع.
   - إرشادات مسح الذاكرة المؤقتة (Cache) وتحديث المتصفح.
   - التواصل الفني مع فريق الدعم لحل المشكلات التقنية الطارئة.

8. **معلومات المتجر (store-info - 6 مقالات):**
   - نبذة عن براند DANDY كمتجر مصري موثوق لمستحضرات التجميل الأصلية.
   - **مواعيد العمل الرسمية:** يومياً من 10:00 صباحاً حتى 10:00 مساءً بتوقيت القاهرة.
   - **رقم الدعم الفني عبر واتساب:** `01038941005` (رابط مباشر: `https://wa.me/201038941005`).
   - رابط مركز المساعدة `/help`، صفحة تواصل معنا `/contact-us`، والشروط والأحكام `/terms`.

## 🔍 محرك البحث العربي والذكاء اللغوي المحلي

تم تطوير محرك البحث العربي المدمج داخل `widget/bab-widget.js` ليفهم أسلوب العملاء المصريين والعرب بطريقة طبيعية وفورية:

```
[استعلام المستخدم]
        │
        ▼
[تطبيع النص العربي: إزالة التشكيل، توحيد الألفات أ/إ/آ -> ا، توحيد الياء ى/ي -> ي، التاء المربوطة]
        │
        ▼
[مطابقة حدود الكلمات العربية (Token Boundaries) لمنع التشابه العرضي مثل "عمل" داخل "العملاء"]
        │
        ▼
[نظام التقييم والترجيح متعدد الطبقات: تطابق كلي، جزئي، أسئلة بديلة، مرادفات عامية، تصنيفات]
        │
        ▼
[تسامح الأخطاء الإملائية عبر خوارزمية مسافة ليفنشتاين (Levenshtein Distance) للكلمات الطويلة]
        │
        ▼
[تحقق نسبة التغطية (Token Ratio): يتطلب مطابقة كلمتين على الأقل في الجمل الطويلة غير المرتبطة]
        │
        ▼
[إذا كانت الدرجة >= 45]: عرض أفضل 5 مقالات مرتبة بأعلى دقة
[إذا كانت الدرجة < 45]: تشغيل الرد الذكي المعتمد وتوجيه العميل مباشرة لواتساب 01038941005
```

### أمثلة على استعلامات عامية وفصحى مدعومة بنجاح:
- **الشحن:** `الشحن بكام؟`، `مصاريف التوصيل كام؟`، `سعر الشحن`، `هل التوصيل مجاني؟`، `عايز اعرف تكلفة الشحن` -> تقود فوراً إلى مقال `تكلفة ومصاريف الشحن والتوصيل` ومقال `الشحن المجاني`.
- **التتبع:** `عايز اتابع الاوردر`، `طلبي وصل لفين؟`، `فين الشحنة بتاعتي؟`، `ازاي اتتبع الطلب؟`، `Track my order` -> تقود مباشرة إلى مقال `كيفية تتبع الشحنة والطلب`.
- **الاسترجاع:** `عايز ارجع منتج`، `المنتج وصل تالف`، `وصلني منتج غلط` -> تقود فوراً لمقال `طلب استرجاع منتج أو استرداد المبلغ`.
- **الأخطاء الإملائية:** `تتببع طلبي` (مع حرف باء مكرر) -> يتعرف المحرك فوراً على نية التتبع بفضل مسافة ليفنشتاين.
- **الاستعلامات غير ذات الصلة:** `طريقة عمل الكيكة بالشكولاته` -> يعزل المحرك الكلمات العرضية ويعرض فوراً شاشة عدم توفر نتائج مع زر واتساب الدعم الفني.

## 🖥️ دليل استخدام لوحة التحكم الإدارية (Dashboard Manual)

يمكن الوصول للوحة التحكم عبر المسار `/dashboard/index.html` أو عبر النقر على زر **لوحة التحكم** من البوابة الرئيسية.

### 1. تبويب النظرة العامة (Overview):
- بطاقات إحصائية حية: إجمالي الأقسام، المقالات المفعلة، المقالات المعطلة، والمقالات المكتملة.
- فحص سلامة البيانات التلقائي (Data Health Check): يكتشف فوراً أي مقالات تفتقر لأسئلة بديلة أو كلمات مفتاحية.

### 2. تبويب الأقسام (Categories):
- إضافة قسم جديد مع تحديد المعرف اللاتيني، العنوان العربي، الوصف، والرمز التعبيري (Emoji).
- تعديل مسميات الأقسام وترتيب ظهورها.
- **حذف آمن:** يمنع النظام حذف أي قسم يحتوي على مقالات نشطة لحماية سلامة البيانات ويطلب نقلها أولاً.

### 3. تبويب الأسئلة والأجوبة (Q&A Knowledge Base):
- تصفية متقدمة حسب القسم، وحالة التفعيل، والبحث الفوري في العناوين والمحتوى.
- **محرر المقالات الشامل:**
  - العنوان / السؤال الرئيسي.
  - اختيار القسم التابع له.
  - إضافة روابط داخلية أو خارجية مع التحقق الفوري من سلامة الرابط وخلوه من أي بروتوكولات خطرة.
  - محرر تاجات تفاعلي (Tag Input) لإضافة الأسئلة البديلة، الكلمات المفتاحية، والمرادفات العامية بنقرة زر واحدة أو بمفتاح Enter.
  - نص الإجابة الاحترافي، والخطوات الإرشادية المرقمة.
  - تبديل حالة التفعيل (مفعل / معطل) دون الحاجة لحذف المقال.

### 4. تبويب الكلمات المفتاحية (Keywords Manager):
- فهرس مرئي لجميع الكلمات المفتاحية ومرادفاتها وتكرارها في قاعدة المعرفة لتمكين مدير المتجر من تغطية مصطلحات البحث الشائعة.

### 5. تبويب الردود السريعة وإعدادات المساعد (Settings & Quick Replies):
- تخصيص رسائل الترحيب والاعتذار عند غياب النتائج.
- تعديل مواعيد العمل (10:00 ص - 10:00 م) ورقم واتساب المعتمد (`01038941005`).
- تخصيص ألوان الهوية البصرية الرئيسية والثانوية للمساعد.

### 6. تبويب المعاينة الحية (Live Interactive Preview):
- محاكاة دقيقة وحية لشاشة المساعد كما ستظهر للعميل.
- مزود بشريط **الأسئلة الشائعة للتجربة السريعة (Egyptian Test Chips)**:
  - 🚚 `الشحن بكام؟`
  - 🔍 `طلبي وصل لفين؟`
  - 🎁 `شحن مجاني`
  - ⏱️ `مدة التوصيل`
  - 🔄 `عايز ارجع منتج`
  - 🔑 `نسيت كلمة المرور`
  - ✨ `العناية بالبشرة`
  - 🕒 `مواعيد العمل`
- نقرة واحدة على أي زر تختبر استجابة المساعد وسرعة وترتيب نتائجه فورياً.

### 7. التصدير والاستيراد المتقدم (Strict Import / Export):
- **تصدير (Export):** تصدير قاعدة المعرفة المحدثة بصيغة JSON مفحوصة وصالحة للنشر فوراً في `data/knowledge.json`.
- **استيراد صارم (Strict Import):** يفحص الملف قبل الحفظ باستخدام دالة `validateKnowledgeData()`. إذا احتوى الملف على أخطاء هيكلية أو روابط خطرة، يرفض النظام استبدال البيانات ويعرض رسائل تحذيرية مفصلة للمدير لحماية المتجر.
- **استعادة البيانات الافتراضية (Reset to Default):** تمكن المدير من استعادة الـ 56 مقالاً الأصلية بضغطة زر مع رسالة تأكيد احترازية.

## 🔒 الأمان، حماية الروابط، وفحص البيانات

تم تطبيق نموذج أمان صارم ومشدد (Zero-Trust Security Model):

1. **فحص وتعقيم الروابط (URL Sanitization & Whitelisting):**
   - تم تنفيذ دالتي `isValidUrl(url)` و `sanitizeUrl(url, baseUrl)` داخل المكون ولوحة التحكم.
   - **حظر البروتوكولات الخطرة:** يتم حظر وإلغاء أي رابط يبدأ بـ:
     - `javascript:` (حظر ثغرات XSS تماماً)
     - `data:`
     - `vbscript:`
     - `file:`
     - `blob:`
     - الروابط النسبية للبروتوكول مثل `//evil-domain.com`.
   - **الروابط المسموحة فقط:** الروابط الآمنة `https://`، وروابط واتساب المعتمدة `https://wa.me/201038941005`، والمسارات الداخلية لمتجر DANDY التي تبدأ بـ `/` (يتم دمجها تلقائياً مع رابط المتجر الرسمي `https://dandy-ebon.vercel.app`).
   - إضافة خواص الأمان التلقائية `target="_blank" rel="noopener noreferrer"` لجميع الروابط الخارجية.

2. **خصوصية وسرية بيانات العملاء:**
   - المساعد مبرمج بحيث **لا يطلب أو يخزن أرقام بطاقات ائتمان، أو أرقام هواتف، أو كلمات سر، أو أكواد سرية للطلبات داخل واجهة الشات**.
   - يتم توجيه العميل بخصوصية تامة لصفحة التتبع الرسمية أو لواتساب الإدارة.

## 🚀 دليل دمج المساعد في موقع DANDY (Astro Integration Guide)

تم تجهيز المكون ليعمل بنظام التضمين السلس دون أي تعارضات مع عناصر متجر DANDY المبني بإطار عمل Astro:

### 1. مسارات الملفات الثابتة في مشروع DANDY:
انسخ الملفات الثلاثة إلى مجلد `public` الخاص بمشروع DANDY كالتالي:
```text
your-astro-project/
└── public/
    └── assets/
        └── bab/
            ├── widget/
            │   ├── bab-widget.js
            │   └── bab-widget.css
            └── data/
```

## 🌐 English Technical Reference

### Overview & Architecture
**B.A.B (Beauty Assistant Bot)** is an ultra-lightweight, deterministic, rule-based customer support assistant and administrative dashboard purpose-built for the **DANDY** beauty e-commerce store (`https://dandy-ebon.vercel.app`).

### Core Design Principles
1. **100% Rule-Based & Deterministic:** No AI, LLM, or external API dependencies. Zero operating costs, zero token costs, and 100% predictable responses.
2. **Native Web Component with Shadow DOM:** Packaged as `<dandy-bab-widget>` with encapsulated CSS and scoped DOM, preventing style bleeding into the host e-commerce website.
3. **Preloaded 56 FAQs across 8 Categories:** Comprehensive customer support knowledge covering orders, shipping, tracking, product lines, returns, user accounts, technical help, and store information with strict adherence to confirmed DANDY store parameters.
4. **Sub-millisecond In-Browser Arabic Search:** Complete Arabic normalization (diacritics, Alef variants, Yaa/Alef Maqsura, Taa Marbuta), token-boundary matching, Egyptian dialect synonyms, Levenshtein distance typo tolerance, and safe fallback thresholds to official WhatsApp support.
5. **Zero-Trust URL Sanitization:** Blocks `javascript:`, `data:`, `vbscript:`, `file:`, `blob:`, and protocol-relative links, resolving relative paths safely against `https://dandy-ebon.vercel.app`.
6. **Local Browser Administration Dashboard:** Full CRUD management for FAQs and categories, tag inputs, live embedded widget preview with one-click Egyptian test chips, and strict JSON import/export validation.
