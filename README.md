# B.A.B — Beauty Assistant Bot
## مساعد الدعم الفني الذكي والقائم على القواعد لمتجر DANDY

**B.A.B** هو نظام دعم فني وتوجيه للعملاء مستقل وخفيف الوزن، تم تصميمه خصيصاً لمتجر **DANDY** لمستحضرات التجميل والعناية بالبشرة والشعر (`https://dandy-ebon.vercel.app`).

---

## 💎 الفلسفة والمفهوم الأساسي

> **B.A.B ليس روبوت ذكاء اصطناعي (NOT an AI Chatbot)**

يعمل المساعد بالكامل عبر:
- أسئلة وأجوبة محددة ومسبقة الاعتماد.
- تصفح هرمي موجه (Guided Navigation).
- محرك بحث عربي محلي وفوري (100% Local Search) يعمل داخل المتصفح بدون أي استدعاءات خارجية أو خوادم خلفية.
- اقتراحات فورية أثناء الكتابة.
- روابط آمنة ومباشرة لصفحات متجر DANDY الرسمية.
- خيار التصعيد والتواصل المباشر مع موظفي خدمة العملاء عبر **واتساب (01038941005)**.

---

## 🛠️ التقنيات والمواصفات المعمارية

تم بناء النظام بدون أي اعتمادية على أطر عمل ثقيلة أو خدمات مدفوعة لضمان أقصى درجات السرعة والعزل:
- **HTML5 & CSS3** بهوية DANDY البصرية الراقية.
- **Vanilla JavaScript (ES Modules)**.
- **مكون ويب أصيل (Native Web Component)**: `<dandy-bab-widget>`.
- **Shadow DOM**: لعزل أنماط المساعد بالكامل ومنع أي تداخل مع أنماط المتجر.
- **قاعدة معرفة بتنسيق JSON**: مخزنة في `data/knowledge.json`.
- **تخزين محلي (localStorage)**: لحفظ تعديلات لوحة التحكم الإدارية تلقائياً داخل متصفح المدير.

## 🔍 محرك البحث العربي المحلي (Local Arabic Search)

يقوم المحرك بالبحث الفوري في قاعدة المعرفة المحملة في الذاكرة دون الحاجة لأي اتصال بالإنترنت بعد التحميل الأولي:

1. **تطبيع الحروف والنصوص العربية (Arabic Normalization):**
   - إزالة علامات التشكيل والتنوين بالكامل (`[\u064B-\u065F\u0670]`).
   - إزالة علامة التطويل / الكشيدة (`\u0640`).
   - توحيد جميع أشكال الألف (`أ`, `إ`, `آ`, `ٱ`) إلى `ا`.
   - توحيد الياء والألف المقصورة (`ى`, `ي`) إلى `ي`.
   - معالجة التاء المربوطة والهاء في البحث.
   - تجاهل علامات الترقيم وتوحيد المسافات.

2. **الترتيب وترجيح النتائج (Scoring & Ranking):**
   - **الدرجة القصوى (150-140):** تطابق العنوان أو السؤال الرئيسي التام.
   - **درجة مرتفعة (120-100):** تطابق الأسئلة البديلة أو الكلمات المفتاحية التامة.
   - **درجة متقدمة (90-70):** تطابق المرادفات وتضمين العبارة في العنوان.
   - **تسامح مع الأخطاء الإملائية (Typo Tolerance):** باستخدام خوارزمية Levenshtein Distance للكلمات التي تتكون من 4 أحرف فأكثر.

3. **حالة عدم وجود نتائج (No-Results State):**
   - عرض رسالة عربية مهذبة ومريحة تفيد بعدم توفر إجابة مسجلة حالياً.
   - إتاحة خيارين فوريين: العودة للرئيسية أو فتح محادثة مباشرة مع خدمة العملاء عبر واتساب.

## 📋 ميزات لوحة التحكم المحلية (Local Dashboard)

لوحة تحكم احترافية باللغة العربية مخصصة لمدير المتجر دون الحاجة لأي قاعدة بيانات سحابية:
1. **نظرة عامة (Overview):** إحصائيات واقعية محسوبة من البيانات (إجمالي الأقسام، المقالات المفعلة/المعطلة، مقالات بدون كلمات مفتاحية) مع تنبيهات فحص السلامة (Data Validation).
2. **إدارة الأقسام (Categories):** إضافة، تعديل، حذف آمن (مع منع الحذف غير المقصود أو إعادة توزيع المقالات)، وإعادة ترتيب.
3. **إدارة الأسئلة والإجابات (Q&A):** محرر كامل للمقالات مع صيغ الأسئلة البديلة، الكلمات المفتاحية، المرادفات، الخطوات المرقمة، والروابط الآمنة.
4. **فهرس الكلمات المفتاحية (Keywords Manager):** استعراض شامل للكلمات المفتاحية واكتشاف المقالات التي تفتقر لكلمات بحث.
5. **الردود السريعة (Quick Replies):** إدارة الأزرار الترحيبية المعروضة في شاشة المساعد الأولى.
6. **إعدادات المساعد (Settings):** تعديل الاسم، الوصف، مواعيد العمل (10:00 ص - 10:00 م)، رقم واتساب، ورسائل الترحيب والاعتذار، ومحدد ألوان الهوية البصرية.
7. **المعاينة الحية الفورية (Live Preview):** تجربة المساعد مباشرة بداخل اللوحة وتحديثه لحظياً باستخدام دالة `setKnowledgeData(data)`.
8. **الاستيراد والتصدير (Import / Export):**
   - تصدير ملف `knowledge.json` جاهز للنشر بنقرة واحدة.
   - استيراد ملفات JSON مع الفحص والتحقق الصارم من صحة الهيكل.
   - استعادة البيانات الافتراضية مع رسالة تأكيد.

## 🚀 دليل ربط المساعد بمتجر DANDY المستقبلي

تم تصميم المساعد ليكون مستقلاً تماماً بحيث يمكن دمجه في موقع DANDY دون تعديل ملفات جافاسكريبت أو فايربيس للموقع الأصلي:

### الخطوة 1: نسخ الملفات
يتم نسخ مجلد الـ widget وقاعدة البيانات إلى:
```text
public/
└── assets/
    └── bab/
        ├── widget/
        │   ├── bab-widget.js
        │   └── bab-widget.css
        └── data/
            └── knowledge.json
```

### الخطوة 2: الإدراج في قالب الموقع (`src/layouts/BaseLayout.astro`)
يتم وضع الكود التالي قبل إغلاق وسم `</body>`:

```html
<!-- DANDY B.A.B Customer Support Assistant Widget -->
<dandy-bab-widget
  knowledge-src="/assets/bab/data/knowledge.json">
</dandy-bab-widget>

<script
  type="module"
  src="/assets/bab/widget/bab-widget.js">
</script>
```

### عدم التعارض مع عناصر الموقع:
- **زر واتساب العائم الأصلي:** موجود في أسفل اليمين (Bottom-Right).
- **زر مساعد B.A.B:** يتموضع في أسفل اليسار (Bottom-Left).
- **شريط التنقل السفلي للهواتف المحمولة:** يرتفع المساعد تلقائياً على الشاشات الصغيرة بمقدار `86px` ليبقى حراً ومتاحاً دون حجب أي عنصر أو تداخل.

## 💻 طريقة التشغيل المحلي (Local Running)

المشروع جاهز للتشغيل الثابت على أي نظام تشغيل (Windows / Mac / Linux):

### 1. باستخدام بايثون (موصى به لمستخدمي Windows):
```bash
python -m http.server 8000
```
ثم افتحي المتصفح على الرابط:
`http://localhost:8000`

### 2. باستخدام Node.js / Vite:
```bash
npm run dev
```
ثم افتحي المتصفح على الرابط:
`http://localhost:3000`

- لا يتصل النظام بأي قواعد بيانات لأوامر الشراء أو الحسابات البنكية.
